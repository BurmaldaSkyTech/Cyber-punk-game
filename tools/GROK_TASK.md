РОЛЬ: экстрактор правил. Источник истины — приложенный PDF Cyberpunk RED Core Rulebook.
Вход: REVIEW_BUNDLE.json (константы текущего кода и список нужных ключей).

ЗАДАЧА A — заполнить rules_skeleton точными значениями из книги.
ЗАДАЧА B — сверить code_constants с книгой и выписать расхождения.

ЖЁСТКИЕ ТРЕБОВАНИЯ:
1. Верни ТОЛЬКО JSON по схеме output_schema из бандла. Без прозы, без markdown.
2. Каждая запись обязана иметь "page" — фактический номер страницы PDF, где это написано.
3. Каждая запись обязана иметь "quote" — дословную цитату не длиннее 200 символов,
   которая СОДЕРЖИТ само значение (число/название). Без цитаты запись недействительна.
4. ЗАПРЕЩЕНО додумывать, интерполировать и брать значения из памяти или из интернета.
   Если в книге нет ответа — запиши в "not_found" с причиной, а не выдумывай value.
5. Таблицы (armor/weapons/dv/programs) возвращай объектом {ключ: {поля...}} строго как в книге,
   с сохранением единиц измерения (eb, SP, d6 и т.п.).
6. Если код совпадает с книгой — verdict "ok". Если расходится — "mismatch" и book-значение.
7. confidence: high — значение прямо в таблице/тексте; medium — выведено из соседнего правила;
   low — сомнение. При low обязательно добавь поле "note" с описанием сомнения.
8. Не переписывай формулировки книги: quote дословная, включая регистр и знаки.

ПОРЯДОК РАБОТЫ: ищи разделы по оглавлению (создание персонажа, бой и DV, броня,
оружие, кибервар, нетраннинг, снаряжение). Обрабатывай по одному разделу за раз,
сверяй номера страниц с нумерацией PDF, а не с внутренней нумерацией книги.
